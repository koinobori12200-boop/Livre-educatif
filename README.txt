MON PETIT MONDE — V1
=====================

Fichiers :
- index.html : application complète (pages, exercices, coloriage, narration vocale, espace parent).
- manifest.json : configuration PWA.
- sw.js : service worker pour le cache hors-ligne après première visite.
- icon-192.svg : icône.

MISE EN LIGNE SUR GITHUB PAGES
1. Crée un dépôt GitHub (par exemple mon-petit-monde).
2. Téléverse les 4 fichiers à la racine du dépôt.
3. Dans Settings > Pages, choisis Deploy from a branch, branche main, dossier /root.
4. Ouvre l'adresse fournie par GitHub Pages.
5. Sur Android, ouvre le site dans Chrome puis menu ⋮ > Installer l'application ou Ajouter à l'écran d'accueil.
